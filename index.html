// flagship · active
EEG-Controlled Wheelchair via Motor Imagery
A real-time BCI system that translates imagined left/right hand movements into wheelchair navigation commands. Uses 8-channel OpenBCI EEG, Common Spatial Patterns for feature extraction, and a CNN for classification.
Status: Data collection phase III · Acc: 74.2% · ITR: ~18 bits/min
// infrastructure
Open BCI Data Pipeline & Annotation Toolkit
A modular Python toolkit for EEG collection, preprocessing, epoching, and labeling. Designed for reuse across BCI paradigms. Will be released open-source upon paper submission.
Language: Python · License: MIT (pending) · Docs: In progress
