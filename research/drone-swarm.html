// swarm intelligence · autonomous systems · active
Drone Swarm
via Decentralized Control.
A multi-agent autonomous drone platform exploring swarm intelligence and distributed coordination algorithms. Targeting intent-based swarm direction through BCI integration.
// overview

This project builds a platform for researching swarm intelligence using a small fleet of autonomous quadrotors. The core question: how do you coordinate multiple agents efficiently without a central controller — and can that coordination eventually be driven by decoded human intent?

The current system runs 5 Crazyflie 2.1 drones communicating over a peer-to-peer UDP mesh. Each drone runs an onboard consensus algorithm that negotiates formation positions and obstacle-avoidance priorities locally, without routing commands through a ground station.

// control architecture

The swarm operates in three layered control modes. At the lowest level, each drone runs a PID attitude controller and a local collision-avoidance reactive layer. Above that, a distributed consensus protocol — based on a modified Raft variant — lets drones agree on a shared formation target within ~45 ms.

The high-level planner is where we're iterating most actively. We've implemented and compared two approaches: a hand-coded rule-based planner for benchmarking, and a centralized-training / decentralized-execution reinforcement learning policy trained in simulation using Isaac Gym. The RL policy transfers to real hardware with a ~15% performance drop, which we're closing through domain randomization.

The third planned control mode is BCI-driven: decoded motor imagery or imagined spatial directions from the EEG wheelchair project would be mapped to swarm formation commands, allowing a user to direct the group with thought alone.

// hardware

Each drone is a Bitcraze Crazyflie 2.1 with a Flow Deck v2 (optical flow + ToF ranging for indoor positioning) and a Multi-ranger Deck for 360° obstacle detection. Ground truth position tracking during development uses a 6-camera Vicon motion capture system in the VT Aerospace Lab.

The base station runs the formation planner and BCI bridge on an Intel NUC, communicating with the swarm via Crazyradio PA at 2.4 GHz. Custom firmware modifications expose additional telemetry fields and allow dynamic parameter updates mid-flight.

// related & next steps

The BCI integration arm of this project depends directly on the EEG-Controlled Wheelchair decoder pipeline — decoded motor imagery commands will be remapped from wheelchair navigation vectors to swarm formation targets.

Near-term priorities are closing the sim-to-real gap further via domain randomization, expanding to 10 drones, and designing the first closed-loop BCI swarm control user study.
